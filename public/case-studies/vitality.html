Application Development · Case Study 03

Vitality Loop

An independent wellness and rewards application concept exploring how activity tracking, progress summaries and points-based rewards can be brought together in a straightforward digital experience.

View Prototype ↗ Back to Portfolio
Project type Independent App Concept
Focus UI/UX & Application Development
Technology JavaScript, Node.js, Express, SQLite
01 · Overview

Project Overview

Vitality Loop is a portfolio application concept focused on presenting personal activity information and reward-related features through a central dashboard.

The concept brings together activity logging, progress summaries and a points-based rewards experience. The project provided an opportunity to explore the connection between interface design and backend application functionality.

02 · Opportunity

The Design Challenge

Activity and rewards information can become difficult to follow when presented across disconnected screens. Vitality Loop explores a more structured experience in which users can view their activity information and understand their progress from one place.

Information clarity

Present activity information and progress summaries in a clear, accessible dashboard.

Engagement

Explore a points-based rewards concept that connects recorded activity with a visible progress system.

03 · Objectives

Project Objectives

  • Create a consistent and easy-to-navigate application interface.
  • Present activity information through a central dashboard.
  • Allow activity entries to be recorded and displayed.
  • Explore a points-based rewards feature.
  • Connect the frontend experience to backend data services.
  • Practise responsive interface and application development.
04 · Key Features

Core Application Features

FEATURE 01

Activity Dashboard

A central interface for viewing activity information and progress summaries.

FEATURE 02

Activity Logging

An interface for capturing activity entries and presenting recorded information.

FEATURE 03

Points-Based Rewards

A rewards concept that connects activity records with points and progress.

FEATURE 04

Activity Summaries

Dynamically retrieved information helps present recorded activity in an organised format.

05 · Development Process

Design and Development Approach

The project brought together interface planning, frontend implementation and backend development. The focus was on creating a connected application experience rather than treating the interface and data layer as separate elements.

STEP 01

Structure

Identify the main application areas and organise the information around the dashboard experience.

STEP 02

Interface Development

Build the application screens and responsive layouts using frontend technologies.

STEP 03

Backend Integration

Connect application functionality to backend endpoints and persistent data storage.

STEP 04

Validation

Implement server-side validation to support consistent handling of submitted information.

06 · Technical Implementation

Technology Stack

Frontend

HTML, CSS and JavaScript for application structure, interface styling and interactive functionality.

Backend

Node.js and Express for server-side application logic and REST API endpoints.

Database

SQLite for persistent storage of application data.

Application Logic

Server-side validation and dynamically retrieved activity summaries to connect the interface with stored information.

07 · Learning and Reflection

Key Learnings

Developing Vitality Loop provided an opportunity to work across the frontend and backend layers of an application.

The project strengthened my understanding of how interface structure, API communication, validation and database persistence contribute to a connected digital product.

It also reinforced the importance of presenting information clearly and maintaining consistency across different application sections.
