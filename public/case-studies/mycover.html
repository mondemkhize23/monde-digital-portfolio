Case Study / Insurance Technology

MyCover.

Designing an insurance self-service portal concept that brings essential policy and claims interactions into one accessible digital experience.

Project type Independent concept
Focus UI/UX & Web Development
Technologies HTML, CSS, JavaScript, Node.js

01 / Overview

Project overview

MyCover is an independent insurance self-service portal concept developed to demonstrate how customers could access key insurance services through a structured digital interface.

The concept

A centralised customer experience for accessing a dashboard, submitting claims and reviewing previously submitted claim records.

My contribution

Designed and developed the interface and supporting application functionality, including API integration, data validation and database operations.

02 / Opportunity

The problem space

Insurance-related interactions can involve multiple steps and different types of customer information. MyCover explores a more organised self-service experience where important actions and information are presented in a single interface.

03 / Objectives

Project objectives

Clear navigation

Organise the main customer actions into an interface that is straightforward to navigate.

Claims management

Demonstrate a structured process for submitting claims and viewing claim history.

Data handling

Connect the interface to backend services that validate and store demonstration records.

Responsive experience

Build an interface that adapts to different screen sizes and device types.

04 / Features

Key features

The prototype brings together several core self-service interactions.

  • Customer dashboard
  • Claims submission interface
  • Claim history table
  • Structured form inputs
  • Backend API integration
  • SQLite record storage
  • Server-side validation
  • Responsive layouts

05 / Technical implementation

Bringing the concept to life

The application combines a front-end interface with a Node.js and Express backend. REST API endpoints support the submission and retrieval of demonstration claim records, while SQLite provides persistent storage. Validation is applied on the server to support structured data handling.

HTML5 CSS3 JavaScript Node.js Express.js REST API SQLite Responsive Design

06 / Learning

What this project demonstrates

MyCover demonstrates my ability to connect interface development with backend application functionality. It provided practical experience in structuring customer-facing workflows, handling form submissions, working with REST APIs and persisting application data.
