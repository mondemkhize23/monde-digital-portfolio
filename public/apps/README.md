# Vitality Loop, ClearPath, MyCover — concept prototypes

Independently developed concept prototypes. They are not launched financial or insurance products and are not affiliated with, endorsed by, or representative of Discovery or any other financial or insurance provider. Fictional data only.

Front-end only: HTML, CSS and vanilla JavaScript. Data is saved in the browser (localStorage). There is no server, API or database.

## Open them
Double-click `index.html` in each app folder, or serve this folder with any static server
(for example `python3 -m http.server 8000`, then open http://localhost:8000/apps/vitality/).

## Run the tests (optional)
`npm i -D playwright`, serve the `public` folder on port 8123, then `node tests/e2e.js`.
